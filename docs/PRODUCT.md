# GitDorked

A searchable OSINT + GitHub research toolbox that turns query templates, repository URL tools, and repeatable research recipes into one mobile-friendly launcher.

Primary surfaces:
1. Dorks — search/browse query templates.
2. Builder — fill variables and produce a copy/launch-ready query.
3. GitHub Tools — paste a repo URL and get allowlisted repo intelligence actions.
4. Recipes — guided multi-step research workflows.
5. Favorites — local saved tools and queries.
6. Repo Audit — authorized, non-invasive checks with secret-value redaction.

MVP is local/offline-first. No mandatory AI API.
